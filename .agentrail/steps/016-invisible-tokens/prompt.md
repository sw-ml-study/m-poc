Invisible tokens must announce themselves in callouts and focus (pages/rosetta.js, style.css). The Math face carries multiplication as U+2062 INVISIBLE TIMES so juxtaposition (wx, η ∂L/∂w) has a focus target; its callout's leader then points at empty space between two glyphs, which the user found misleading. Fix: for any token whose visible text is empty or an invisible character (U+2062, U+2063, U+200B), (1) the callout's title says the glyph is invisible and how it is written, e.g. '× multiply (invisible: written by juxtaposition, as wx)', (2) the leader ends at a small hollow marker drawn at the anchor between the neighbouring glyphs (a 6px ring in the warm colour) so the reader sees what is meant, and (3) focus draws the same marker instead of colouring nothing. The width of an invisible token's anchor is taken from the gap between its neighbours' extents. Verify with ?near=mul and ?focus=mul stills; README one line. just check green; commit to main; push.
