Reported on the live demo: no Trace button and key 4 inert after a deploy. Cause: the page fetches data/stones.json and the per-stone fixtures without a version tag, and GitHub Pages serves them with max-age=600, so a browser can pair a new rosetta.js with a stale manifest (no faces list) and drop the Trace face. Fix in pages/rosetta.js: read the ?v= of the page's own script tag and append it to every data fetch, so a deploy that bumps ?v= refreshes the data too; document the rule in the cache-busting note. just check; commit to main; push.
